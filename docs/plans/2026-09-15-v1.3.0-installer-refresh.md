# v1.3.0-installer-refresh: NSIS script + CHANGELOG + version

## What the installer does right now (pre-refresh)
- Buggy: `DisplayVersion` hardcoded `1.1.0` (should be `1.3.0`)
- Describes Core/Full in v1.2.0 terms ("Core is small download, Full is
  everything") — but v1.3.0 switched to a **feature-flag wizard** where
  the "Full" EXE is no longer bigger because of pedalboard + whisper;
  it's bigger because it **pre-bundles the Piper + whisper models**
  so the app works offline with no download
- No "Open install folder" checkbox on the finish page
- Uninstaller removes `$INSTDIR` files + shortcuts but does not clean
  the per-user `PREFS_DIR/feature_assets` (60 MB piper + 150 MB whisper
  per user) — orphaned data
- Registry `BundleChoice` key is written but never read back by the app
  (the app reads `setup.json` via `feature_flags.load_feature_flags`)
  — harmless but the key is dead data

## What we change

### 1. Version bumps
- `DisplayVersion` in the registry write: `1.1.0` → `1.3.0`

### 2. Reframe the bundle-choice text (v1.3.0 semantics)
- Core: "SpeechCraft with on-demand feature downloads — small install,
  pick which models to download later from the setup wizard"
- Full: "SpeechCraft with all feature models pre-bundled — larger
  install, works offline out of the box, no download step needed"
- Update the welcome-page text to say the app is v1.3.0
- Add a "Open install folder" checkbox on the finish page so the user
  can verify the install
- Add `$AppDataDir` cleanup on uninstall: remove `feature_assets`
  subdirectory from `%APPDATA%/SpeechCraft` if it exists
- Keep `DisplayVersion` and `VIProductVersion` at 1.3.0 (already set)
- Remove the dead `BundleChoice` registry write — it's never read by
  the app (the app reads `setup.json`), so writing it just creates
  stale data. Replace it with a `DisplayVersion`-only Uninstall entry
  + `Publisher` (the standard Add/Remove Programs keys)

### 3. Uninstall cleanup
- Remove `$INSTDIR\SpeechCraft_Studio_Core.exe`, `..._Full.exe`,
  `Uninstall.exe` (existing)
- Remove `feature_assets` from `%APPDATA%\SpeechCraft` — the
  downloaded Piper / whisper models (this is the new bit)
- Remove Start Menu shortcuts (existing)
- Remove registry keys (existing, kept)

### 4. CHANGELOG.md
- Move `[Unreleased]` entries into `[1.3.0]` (the release is now live)
- Add an "Installer" section noting the v1.3.0 installer is the
  feature-flag version

## Test
- No CI test for NSIS itself; verify locally:
  - `makensis` compiles with no errors
  - `dist/SpeechCraft_Studio_Setup.exe` produces (578 MB expected,
    ~ same as before since both EXEs are embedded)

## Out of scope
- Rebuilding the Core/Full PyInstaller EXEs themselves — the dist
  folder already has them from the last CI build (19:10 / 20:42 Sep 14)
- CI pipeline changes — the installer build step in `.github/workflows`
  is unchanged; it just calls `makensis` on the updated script
