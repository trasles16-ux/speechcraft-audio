# v1.3.0-feature-toggling: Wizard download button, menu gating, engine wiring

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Make the v1.3.0 wizard actually download the models the user enables, and make the app's menu items + code paths respect `FeatureFlags` + `FeatureState` — so an enabled feature works and a disabled one is absent, not just "greyed out in the wizard".

**Architecture:** Three layers, all building on PR #3 (`feature_manager.py`) and PR #2 (wizard shell):

1. **`feature_toggling.py`** (new, pure-logic) — the decision layer. A single `FeatureGate` dataclass + `build_gates(flags, state)` function that maps each flag to a `GateDecision` (enabled / disabled / needs-download / unavailable). Pure logic, no wx. This is the single source of truth the menu bar and the wizard both read, so they can't disagree.
2. **Wizard download step** (wx) — a new `DownloadPage` inserted into the wizard between TTS engines and Data location. It shows one row per *enabled-and-missing* asset (from `FeatureGate.needs_download`), each with a "Download" button + `wx.Gauge` progress bar + a live status label. A Download-all button runs them in sequence. Cancel deletes the `.part`. Downloads run in a `threading.Thread` so the UI stays responsive; progress hops to the GUI thread via `wx.CallAfter`.
3. **Menu gating in `audio_editor.py`** (wx) — the main frame's menu construction consults `build_gates()` once at startup and hides (not disables) menu items for features that are off. Whisper + Piper engine imports are already lazy (`studio_recorder`, `piper_tts_engine`) so a missing model just means the user re-runs the wizard; no crash path.

**Tech Stack:** Python 3.11, wxPython 4.x, `threading`, `feature_manager` (PR #3), `feature_flags` (PR #1). No new third-party deps.

### The wizard Download page

Inserted as page 4 (index 3), pushing Data location + Summary to 5/6. The wizard grows from 5 to 6 pages. The `PAGE_NAMES` tuple and `GetPageCount`-based nav logic in `setup_wizard.py` are updated automatically because they're data-driven.

The page:
- Reads `build_gates(flags)` at construction.
- For each `(feature, asset)` in `gates_to_download_list(gates)` **AND** where `is_downloadable(...)` is True → one row: `[asset description] [Gauge] [status label] [Download button]`.
- "Download all" button at the top runs them sequentially in one thread.
- Each row's Download button runs just that asset.
- Cancel button (per row + a global "Cancel all") sets a `threading.Event`; the worker checks it between files and between chunks via `cancel_check`.
- Progress: `wx.Gauge` (0..100, derived from `bytes_done / total_asset_bytes`) + a live `wx.StaticText` label `"Downloading model.bin (23/60 MB)"` updated via `wx.CallAfter` from the worker thread.
- On success: the row's button becomes "Downloaded ✓" (disabled), status label says "Ready". On failure: status label says the error, button re-enables for retry.
- All controls get `SetName()` (NVDA). The Gauge gets `SetName(f"{asset} download progress")`.

```python
# feature_toggling.py — full module
"""SpeechCraft Studio feature gate logic.

Pure logic — no wx, no downloads. Decides, per feature, whether the
menu should show it and whether the wizard should offer a download.

Two inputs:
- ``flags`` — a :class:`feature_flags.FeatureFlags` (user choices)
- asset readiness — from :mod:`feature_manager` (is the download done?)

One output per feature: a :class:`FeatureGate`.
"""

from __future__ import annotations

from dataclasses import dataclass
from pathlib import Path
from typing import Literal, Final

from feature_flags import FeatureFlags
from feature_manager import is_downloadable, is_ready

GateDecision = Literal["enabled", "needs_download", "disabled", "unavailable"]

#: Maps a feature flag to the feature_manager asset(s) it downloads.
#: None = no download needed (cloud feature, pip package, or pure logic).
#: A list = multiple assets (e.g. piper_tts ships two voices).
FEATURE_ASSET_MAP: Final = {
    "basic_editing": None,
    "pedalboard_effects": None,
    "local_transcription": ("local_transcription", "tiny.en"),
    "cloud_transcription": None,
    "destructive_editing": None,
    "line_placing": None,
    "edge_tts": None,
    "piper_tts": (
        ("piper_tts", "en_GB.cori"),
        ("piper_tts", "en_GB.alan"),
    ),
}


def feature_uses_asset(feature: str) -> list[tuple[str, str]] | None:
    """Return the (feature, asset) pair(s) for a feature, or None.

    - No download  -> None
    - One asset    -> [("local_transcription", "tiny.en")]
    - Two assets   -> [("piper_tts", "en_GB.cori"), ("piper_tts", "en_GB.alan")]

    The map stores a single asset as a 1-tuple of one pair, and a
    multi-asset feature as a tuple of pairs. This normalises both
    shapes to a list so callers can always iterate.
    """
    raw = FEATURE_ASSET_MAP.get(feature)
    if raw is None:
        return None
    # A 2-element tuple (f, a) where both are str is ONE pair.
    if (
        isinstance(raw, tuple)
        and len(raw) == 2
        and isinstance(raw[0], str)
        and isinstance(raw[1], str)
    ):
        return [raw]
    # A tuple of pairs (multi-asset feature)
    return [pair for pair in raw]


@dataclass(frozen=True)
class FeatureGate:
    feature: str
    enabled: bool
    has_asset: bool
    asset_ready: bool
    decision: GateDecision


def build_gates(flags: FeatureFlags, *, state_file: Path | None = None) -> dict[str, FeatureGate]:
    """Build a gate for every feature in FEATURE_ASSET_MAP."""
    gates: dict[str, FeatureGate] = {}
    for feature in FEATURE_ASSET_MAP:
        enabled = getattr(flags, feature, False)
        assets = feature_uses_asset(feature)
        has_asset = bool(assets)

        if not enabled:
            gates[feature] = FeatureGate(feature, False, has_asset, False, "disabled")
            continue

        if not has_asset:
            gates[feature] = FeatureGate(feature, True, False, True, "enabled")
            continue

        # Has assets — check readiness + downloadability
        ready = all(
            is_ready(f, a, state_file=state_file) for f, a in assets
        )
        downloadable = all(
            is_downloadable(f, a) for f, a in assets
        )
        if ready:
            decision = "enabled"
        elif downloadable:
            decision = "needs_download"
        else:
            decision = "unavailable"
        gates[feature] = FeatureGate(feature, True, True, ready, decision)
    return gates


def gates_to_download_list(gates: dict[str, FeatureGate]) -> list[tuple[str, str]]:
    """Return the (feature, asset) pairs the wizard should offer to download.

    Only assets that are NOT ready AND ARE downloadable. Features that
    are disabled don't appear (the user didn't ask for them).
    """
    result: list[tuple[str, str]] = []
    for gate in gates.values():
        if gate.decision != "needs_download":
            continue
        assets = feature_uses_asset(gate.feature)
        if assets:
            for f, a in assets:
                result.append((f, a))
    return result


__all__ = (
    "FEATURE_ASSET_MAP",
    "FeatureGate",
    "GateDecision",
    "build_gates",
    "feature_uses_asset",
    "gates_to_download_list",
)
```

class DownloadPage(_WizardPage):
    """Lists every enabled-and-missing asset and offers a download button.

    One row per (feature, asset) pair from feature_toggling.gates_to_download_list.
    Each row: description label, wx.Gauge progress bar, status StaticText,
    Download button. A "Download all" button runs them in sequence.

    Downloads run in a background thread; progress hops to the GUI
    thread via wx.CallAfter. A Cancel button + per-row cancel sets a
    threading.Event the worker polls.
    """

    def __init__(self, parent, *, flags, state_file=None):
        self._flags = flags
        self._state_file = state_file
        self._cancel_events: list = []
        self._workers: list = []
        self._has_state = True
        super().__init__(parent, name="Download ready")

    def _build_ui(self):
        from feature_toggling import build_gates, gates_to_download_list

        title = wx.StaticText(self, label="Download ready")
        title.SetFont(wx.Font(16, wx.FONTFAMILY_DEFAULT, wx.FONTSTYLE_NORMAL, wx.FONTWEIGHT_BOLD))
        title.SetName("Download ready, heading")
        self._sizer.Add(title, 0, wx.ALL, 16)

        intro = wx.StaticText(
            self,
            label=(
                "Some of the features you chose download model files on "
                "first use. Download them now so they're ready to go, or "
                "you can come back to this page later from the wizard."
            ),
        )
        intro.SetName("Download models for your chosen features, or skip and download later.")
        intro.Wrap(560)
        self._sizer.Add(intro, 0, wx.LEFT | wx.RIGHT | wx.BOTTOM, 16)

        # Build the gate state
        gates = build_gates(self._flags, state_file=self._state_file)
        dl_list = gates_to_download_list(gates)

        self._rows: list[dict] = []

        if not dl_list:
            empty = wx.StaticText(self, label="Everything is ready. Nothing to download.")
            empty.SetName("All selected features are ready, nothing to download.")
            self._sizer.Add(empty, 0, wx.LEFT | wx.RIGHT | wx.BOTTOM, 16)
            self._sizer.AddStretchSpacer(1)
            return

        # "Download all" button
        self._dl_all = wx.Button(self, wx.ID_ANY, "Download all")
        self._dl_all.SetName("Download all missing models")
        self._dl_all.Bind(wx.EVT_BUTTON, self._on_download_all)
        self._sizer.Add(self._dl_all, 0, wx.LEFT | wx.RIGHT | wx.BOTTOM, 12)

        for (feature, asset_name) in dl_list:
            row = self._build_row(feature, asset_name)
            self._rows.append(row)

        self._sizer.AddStretchSpacer(1)

    def _build_row(self, feature: str, asset_name: str) -> dict:
        from feature_manager import get_asset, total_asset_bytes, is_downloadable

        asset = get_asset(feature, asset_name)
        row_sizer = wx.BoxSizer(wx.VERTICAL)

        # Description label
        desc = wx.StaticText(self, label=asset.description or asset.key)
        desc.SetName(f"{asset.key} description")
        row_sizer.Add(desc, 0, wx.LEFT | wx.RIGHT | wx.TOP, 8)

        # Progress + status row
        hz = wx.BoxSizer(wx.HORIZONTAL)
        gauge = wx.Gauge(self, range=100, size=(200, 20))
        gauge.SetName(f"{asset.key} download progress")
        hz.Add(gauge, 0, wx.RIGHT, 8)

        status = wx.StaticText(self, label="Not downloaded")
        status.SetName(f"{asset.key} status")
        hz.Add(status, 0, wx.ALIGN_CENTER_VERTICAL | wx.RIGHT, 8)

        btn = wx.Button(self, wx.ID_ANY, "Download")
        btn.SetName(f"Download {asset.key}")
        btn.Enable(is_downloadable(feature, asset_name))
        hz.Add(btn, 0)
        row_sizer.Add(hz, 0, wx.LEFT | wx.RIGHT | wx.BOTTOM, 8)

        cancel = wx.Button(self, wx.ID_ANY, "Cancel")
        cancel.SetName(f"Cancel download of {asset.key}")
        cancel.Hide()
        cancel.Bind(wx.EVT_BUTTON, lambda e, f=feature, a=asset_name: self._cancel_row(f, a))
        row_sizer.Add(cancel, 0, wx.LEFT | wx.RIGHT | wx.BOTTOM, 8)

        self._sizer.Add(row_sizer, 0, wx.EXPAND)

        cancel_event = threading.Event()
        return {
            "feature": feature,
            "asset": asset_name,
            "gauge": gauge,
            "status": status,
            "button": btn,
            "cancel": cancel,
            "cancel_event": cancel_event,
            "total_bytes": total_asset_bytes(feature, asset_name),
        }

    def get_row_count(self) -> int:
        """Test hook: how many download rows does this page have?"""
        return len(self._rows)

    def _on_download_all(self, event):
        for row in self._rows:
            if row["button"].IsEnabled():
                self._start_download(row)

    def _start_download(self, row: dict):
        import threading as _th
        from feature_manager import download_asset, FeatureDownloadError
        from prefs import PREFS_DIR

        feature = row["feature"]
        asset = row["asset"]
        cancel_event = row["cancel_event"]
        row["button"].Disable()
        row["cancel"].Show()
        row["status"].SetLabel("Downloading…")
        row["gauge"].SetValue(0)

        def _progress(asset_key, done, total):
            if total > 0:
                pct = int(100 * done / total)
                wx.CallAfter(row["gauge"].SetValue, min(pct, 100))
                label = f"Downloading… ({done // (1024*1024)} of {total // (1024*1024)} MB)"
                wx.CallAfter(row["status"].SetLabel, label)

        def _worker():
            try:
                download_asset(
                    feature, asset,
                    dest_dir=PREFS_DIR / "models",
                    progress_cb=_progress,
                    cancel_check=cancel_event.is_set,
                    state_file=self._state_file,
                )
                wx.CallAfter(row["button"].SetLabel, "Ready ✓")
                wx.CallAfter(row["status"].SetLabel, "Downloaded and verified.")
                wx.CallAfter(row["gauge"].SetValue, 100)
            except FeatureDownloadError as exc:
                wx.CallAfter(row["button"].Enable)
                wx.CallAfter(row["button"].SetLabel, "Retry")
                wx.CallAfter(row["status"].SetLabel, f"Failed: {exc.reason}")
            finally:
                wx.CallAfter(row["cancel"].Hide)

        worker = _th.Thread(target=_worker, daemon=True)
        worker.start()
        self._workers.append(worker)

    def _cancel_row(self, feature: str, asset_name: str, event=None):
        for row in self._rows:
            if row["feature"] == feature and row["asset"] == asset_name:
                row["cancel_event"].set()

    def collect(self):
        # Download page doesn't change flags — it acts on them.
        return self._flags

def _apply_menu_gates(self, gates):
    """Hide menu items whose feature is disabled.

    The item→feature map is hardcoded here (menu item labels are
    stable strings). A hidden item is still in the menu bar (NVDA
    skips it) — re-enable in the wizard and relaunch to bring it back.
    """
    LABEL_TO_FEATURE = {
        "Transcribe with AI…": "local_transcription",
        "Transcribe with SpeechRecognition…": "cloud_transcription",
        "Piper TTS…": "piper_tts",
        "Edge TTS…": "edge_tts",
        # Add more as you find the actual labels in _build_menus
    }
    menu = self.GetMenuBar()
    if menu is None:
        return
    for i in range(menu.GetMenuCount()):
        sub = menu.GetMenu(i)
        for item in sub.GetMenuItems():
            label = item.GetItem(label) if hasattr(item, "GetItem") else str(item)
            feature = LABEL_TO_FEATURE.get(label)
            if feature and not gates[feature].enabled:
                item.Enable(False)  # disable, not hide — safer for NVDA

## Risks & open questions

1. **Menu item labels are hardcoded** — the `LABEL_TO_FEATURE` map in Task 3 assumes the labels in `audio_editor.py` match. If the labels differ, the gate silently does nothing. Mitigation: run the app once, check the actual labels, update the map. This is a 5-minute fix.

2. **`feature_toggling.feature_uses_asset` returns a list** — the single-asset case returns `[(f, a)]` not `(f, a)`. The `gates_to_download_list` function flattens it. If a future feature has 3+ assets, the map just gets longer — no code change.

3. **Download thread + `wx.CallAfter`** — the worker thread must call `wx.CallAfter` for every GUI mutation (SetValue, SetLabel, Enable/Disable). The code in Task 2 does this. A direct call from the thread will crash wxPython.

4. **`is_ready` is called at gate-build time** — if the user downloads an asset *while the app is running*, the menu gating (computed at startup) won't reflect it until relaunch. That's acceptable: the wizard is the download trigger, and relaunch is already the pattern for flag changes (see `feature_flags.py` docstring).

5. **`DownloadPage` needs `threading` imported at module level** — add `import threading` to the top of `setup_wizard_pages.py`.
