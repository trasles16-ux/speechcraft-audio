SpeechCraft Studio — API Reference

For developers contributing to SpeechCraft. This document covers the main classes and their public APIs.

Main Application

class SpeechCraftFrame(TTSMenuMixin, wx.Frame)

The main application frame. Inherits from TTSMenuMixin for TTS functionality and wx.Frame for window management.

Key Methods

__init__(parent, title="SpeechCraft Studio")
Initialise the main frame with menus, toolbar, and status bar.
on_help_manual(event)
Open the user manual HTML file in the default browser.
on_help_quick(event)
Open the quick reference HTML file in the default browser.
on_report_bug(event)
Open the in-app bug report dialog. Collects error log and pre-fills GitHub issue URL.

Text-to-Speech Mixin

class TTSMenuMixin

Mixin that provides TTS menu handlers. Extracted from SpeechCraftFrame to reduce coupling.

Methods Inherited by SpeechCraftFrame

on_edge_tts(event)
Open the Edge TTS dialog. Uses edge_tts_engine.EdgeTTSEngine.
on_piper_tts(event)
Open the Piper TTS dialog. Uses piper_tts_engine.PiperTTSEngine.

Dialog Modules

dialogs.effects_dialogs

Contains all audio effect dialogs and the AudioClipboard class.

class AudioClipboard

Manages audio data for copy/paste operations across tracks. Requires sounddevice on Windows.

Effect Dialogs

EffectSettingsDialog
Base class for effect dialogs with Before/After toggle.
CompressorPresetDialog
Compressor settings with preset save/load.
EQPresetDialog
Parametric equalizer with frequency/gain bands.
BreathSmoothingPresetDialog
Breath detection threshold and attenuation settings.
RoomToneMatchDialog
Sample and apply room tone noise profile.
BatchProcessDialog
Apply effects to multiple files in batch.

dialogs.recording_dialogs

Contains recording and studio dialogs.

class RecordingDialog

Simple recording dialog for capturing audio from microphone.

class StudioRecordingDialog

Full studio with real-time transcription panel and line-by-line placement.

Testing

Running Tests

pytest tests/                          # All tests
pytest tests/test_dialog_smoke.py      # Dialog imports and constructs
pytest tests/test_pure_logic.py        # Core logic modules
pytest tests/test_pure_logic.py -v     # Verbose output

Test Structure

  • tests/conftest.py — Session-scoped wx_app fixture
  • tests/test_dialog_smoke.py — 27 tests for dialog classes
  • tests/test_pure_logic.py — 21 tests for audio modules

CI

  • Linux smoke: import tests + pure logic (no wx required)
  • Windows full: all tests including wx dialogs
  • Build: PyInstaller produces SpeechCraft-Windows.zip
