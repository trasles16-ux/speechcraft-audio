Common Workflows

Quick Recording & Export

  1. Ctrl+R to record
  2. Adjust volume with Effects → Normalise
  3. Reduce breaths with Tools → Breath Smoothing
  4. File → Export Audio to save as WAV or MP3

Multi-Track Project

  1. File → New Project
  2. File → Import Audio to add tracks
  3. Record additional voice tracks as needed
  4. Apply effects to individual tracks or the mix
  5. File → Export Audio to render

Audio Description Production

  1. Import video or audio to describe
  2. Record voice-over description
  3. Use Studio Recording for real-time transcription
  4. Apply Auto-Ducker to balance voice and background
  5. Export final mix

NVDA Navigation Tips

  • Use Tab to move between controls in dialogs

  • Press Esc to close any dialog without saving

Troubleshooting

Crash on startupCheck speechcraft_error.log in project folder

Project File Info

  • Project files have .speechcraft extension
  • They are JSON text files — portable and human-readable
  • Keep audio files in the same folder as the project file
  • Project data is stored in %APPDATA%\SpeechCraft
