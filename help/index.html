SpeechCraft Studio User Manual

Welcome to SpeechCraft Studio — an accessible audio editing suite for audio-description producers, voice actors, and content creators.

Getting Started

System Requirements

  • Windows 10 or 11
  • Python 3.11 (included in the standalone EXE)
  • FFmpeg (auto-downloaded on first run if missing)
  • Screen reader: NVDA 2024.1+, JAWS 2024+, or Windows Narrator

First Run

On first launch, SpeechCraft will:

  1. Download FFmpeg if not found on your system
  2. Create a project folder in %APPDATA%\SpeechCraft
  3. Set up default effects presets

Menu Overview

File Menu

  • New Project — Create a fresh project with no tracks
  • Open Project — Load an existing .speechcraft project file
  • Save Project — Save current project (Ctrl+S)
  • Save Project As... — Save as a new file
  • Import Audio — Add audio files to the current project
  • Export Audio — Render and export the project to WAV or MP3
  • Exit — Close the application

Editing Menu

  • Undo — Undo last action (Ctrl+Z)
  • Redo — Redo last undone action (Ctrl+Y)
  • Cut — Cut selected audio (Ctrl+X)
  • Copy — Copy selected audio (Ctrl+C)
  • Paste — Paste from clipboard (Ctrl+V)
  • Delete — Delete selected audio (Del)
  • Select All — Select entire track (Ctrl+A)

Effects Menu

  • Compressor — Reduce dynamic range for consistent volume
  • De-esser — Reduce harsh sibilance sounds
  • Equalizer — Adjust frequency bands (parametric EQ)
  • Noise Gate — Remove background noise between speech
  • Normalise — Boost audio to peak at -1 dB
  • Room Tone Match — Match background noise profile from sample
  • Batch Process — Apply effects to multiple files

Tools Menu

  • Breath Smoothing — Automatically reduce breath sounds
  • Auto-Ducker — Duck background music during speech
  • Word Alignment — Sync transcript text to audio timestamps

Record Menu

  • Record New Track — Record from microphone to new track
  • Studio Recording — Record with real-time transcription

TTS Menu

  • Edge TTS — Microsoft cloud-based text-to-speech (requires internet)
  • Piper TTS — Local neural TTS (requires piper.exe setup)

Help Menu

  • User Manual — This document
  • Quick Reference — Keyboard shortcuts and common tasks
  • Report a Bug... — Open bug report dialog (collects error log automatically)

Recording

Basic Recording

  1. Select Record → Record New Track (or press Ctrl+R)
  2. Choose your input device from the dialog
  3. Press Record to start
  4. Press Stop when done

Studio Recording with Transcription

  1. Select Record → Studio Recording
  2. The studio opens with real-time transcription panel
  3. Record your voice — transcription appears as you speak
  4. Use line-by-line placement to position transcript text
  5. Save project when finished

Effects Usage

Before & After Comparison

Each effect dialog has a "Before & After" toggle. Use this to compare the original and processed audio:

  1. Open an effect dialog (e.g., Effects → Compressor)
  2. Adjust settings and preview
  3. Toggle "Before & After" to hear the difference
  4. Click Apply to commit changes

Presets

Save your favourite effect settings as presets:

  1. Open any effect dialog
  2. Adjust settings to your liking
  3. Click "Save Preset" and give it a name
  4. Load presets later from the same dialog

Text-to-Speech

Edge TTS

Microsoft cloud-based TTS — no local files needed, just internet:

  1. Select TTS → Edge TTS
  2. Choose a voice from the dropdown
  3. Paste or type your text
  4. Click "Generate" to create audio

Piper TTS

Local neural TTS — works offline, no internet required:

  1. Download Piper from GitHub
  2. Place piper.exe and all DLLs in the project folder
  3. Select TTS → Piper TTS
  4. Choose a voice and generate audio
Note for NVDA users: All comboboxes and text controls now announce proper names. If you hear "unknown", please report it via Help → Report a Bug.

Bug Reporting

If you encounter a bug:

  1. Select Help → Report a Bug...
  2. Fill in the dialog (what you expected, what happened, steps to reproduce)
  3. Click "Generate Report" — this opens your browser with a pre-filled GitHub issue
  4. The report URL is also copied to your clipboard as fallback

If the app crashes, check speechcraft_error.log in the project folder for details.

Project Files

Projects are saved as .speechcraft files — these are JSON files that reference audio files by path. Keep your audio files in the same folder as the project file for portability.
