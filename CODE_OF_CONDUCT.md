# Code of Conduct

## Our pledge

We want this project to be welcoming to everyone, regardless of experience level, background, disability, ethnicity, gender identity, language, nationality, race, religion, or sexual orientation.

## Our standards

Examples of behaviour that contributes to a positive environment:

- Being respectful of differing viewpoints and experiences
- Gracefully accepting constructive criticism
- Focusing on what is best for the project and its users
- Showing empathy towards other community members

Examples of unacceptable behaviour:

- Harassment, discrimination, or personal attacks in any form
- Publishing others' private information without permission
- Trolling, insulting comments, or other unprofessional conduct
- Any conduct that would be inappropriate in a professional setting

## Accessibility and disability

SpeechCraft is built by and for users of assistive technology. Please be especially mindful of:

- **Accessibility in contributions.** New UI without screen-reader support will not be merged. If a contribution introduces a new dialog or widget, the PR description must include NVDA test results.
- **Identity-first language.** This project follows identity-first language: "blind person", "DeafBlind person", "wheelchair user". Person-first language ("person who is blind") is acceptable but not preferred. "The disabled", "the blind" as nouns are not.
- **No inspiration porn.** Do not write copy that frames disabled users as "brave" or "inspiring" for using the app.

## Enforcement

Instances of abusive, harassing, or otherwise unacceptable behaviour may be reported to the project maintainer at <tracy@tracysmith.co.za>. All complaints will be reviewed and investigated and will result in a response that is appropriate to the circumstances.

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
